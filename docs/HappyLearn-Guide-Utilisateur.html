Guide utilisateur

Happy Learn

Ce guide explique comment utiliser Happy Learn en classe ou à la maison : connexion, mission solo, session live, suivi de classe, couverture du programme, studio admin (missions + illustrations), écoute, panneau Couleurs et bascule Classic / NewFront. Aucune connaissance technique n’est requise.

1. Démarrer en 2 minutes

Ouvre Happy Learn dans un navigateur (Chrome, Edge, Safari, Firefox) sur ordinateur ou tablette.

Je suis…Je clique sur…Puis…
ÉlèveÉlèvePrénom libre ou code donné par le professeur
EnseignantEnseignantE-mail + mot de passe (ou lien magique)
Astuce : en démo locale sans compte serveur, l’espace enseignant peut s’ouvrir avec un e-mail seul (identifiant de l’appareil).

2. Guide élève — jouer une mission solo

Parcours recommandé quand tu n’es pas en session de classe.

  1. Connexion élève — entre ton prénom (sans code), puis valide.
  2. Accueil — lance la mission ou change le parcours (niveau / matière).
  3. Niveau & matière — choisis ta classe (CP→CM2) et ta matière : 79 missions officielles sont disponibles selon le thème.
  4. Présentation — lis l’objectif de la séance, puis choisis ton univers.
  5. Univers — Football, Rugby, Équitation ou Espace : l’histoire change, les calculs restent les mêmes.
  6. Matériel — cahier (tu tapes tes réponses) ou QCM (propositions mélangées).
  7. Prêt — vérifie tes choix, puis entre dans la mission.
  8. Mission — lis la consigne, réponds, utilise un indice si besoin, continue jusqu’à la récompense.

Pendant la mission

  • Valider envoie ta réponse. Si c’est juste, Néo encourage et l’étape suivante arrive.
  • Un indice t’aide sans donner directement la réponse.
  • Écouter (barre du haut) lit le texte à voix haute ; recliquer pour arrêter.
  • Couleurs ouvre un panneau : mode daltonien et/ou teinte du site.
  • Classic / NewFront change l’apparence (NewFront est l’interface par défaut ; tu peux revenir à Classic).
  • Quitter revient à l’accueil sans gagner la récompense de la mission.
À retenir : Happy Learn ne met pas de note et ne fait pas de classement. L’objectif est de réussir la mission et de gagner une récompense visuelle.

3. Guide élève — rejoindre une session de classe

Quand le professeur lance une session live, tu rejoins avec un code.

  1. Sur Connexion élève, entre le code de session (ex. C82THT).
  2. Choisis ton nom dans la liste de la classe (prénom + nom).
  3. Tu arrives en salle d’attente : patiente jusqu’au lancement de l’activité.
  4. Quand la mission est lancée, choisis ton univers, puis joue.
  5. À la fin (ou si le professeur arrête l’activité), tu reviens en salle d’attente.
  6. Tu peux lever la main (salle d’attente ou mission) pour signaler au professeur que tu as besoin d’aide ; recliquer pour baisser.
Important : en session live, la navigation est verrouillée. Tu restes sur la salle d’attente ou la mission. Si le professeur te déconnecte, ton prénom redevient libre pour une reconnexion.

4. Guide enseignant — préparer sa classe

  1. Connecte-toi en Enseignant.
  2. Dans Espace professeur, crée ou sélectionne une classe (popup « Tes classes »).
  3. Ajoute les élèves (prénom et nom) : ils apparaîtront dans le code de session.
  4. Note le code de classe (partageable) et utilise le pilotage de session pour un code live du jour.
  5. Consulte le suivi (Élèves / Séances / Programme) — sans notes ni classement.
Bonnes pratiques : prépare la liste d’élèves avant l’heure de classe. Un élève absent du roster ne pourra pas rejoindre via le code session.

5. Guide enseignant — piloter une session live

  1. Ouvre Pilotage de session.
  2. Clique sur Lancer une session : un nouveau code s’affiche (à écrire au tableau).
  3. Suis le roster : connecté / déconnecté / pas encore connecté. Un badge Main levée apparaît si un élève appelle ; clique Vu pour baisser sa main.
  4. Choisis niveau, matière, mission, mode (cahier ou QCM).
  5. Clique sur Lancer l’activité. Chaque élève choisit ensuite son univers.
  6. Pour faire une pause ou changer : Arrêter l’activité renvoie les élèves en salle d’attente.
  7. Terminer la session ferme le code.

Lancer l’activitéPassage de l’attente au choix d’univers / mission
Arrêter l’activitéRetour salle d’attente

6. Guide enseignant — suivi & couverture du programme

L’écran Suivi de classe occupe toute la largeur. Le sélecteur de classe s’ouvre en popup (« Tes classes ») pour laisser la place aux listes.

  1. Ouvre l’espace professeur : le mode Élèves montre le détail par élève.
  2. Passe en mode Séances pour le journal des sessions.
  3. Passe en mode Programme pour voir les thèmes du programme de la matière.
  4. Pour chaque thème, coche App (fait dans Happy Learn) et/ou En classe (traité hors application).
  5. Les pastilles indiquent Traité / Partiel / À faire — en mode daltonien, forme et motifs aident aussi.
Astuce : la couverture programme est enregistrée par classe. Utile pour préparer le conseil de cycle ou le cahier journal.

7. Guide admin — studio missions & illustrations

La création de missions et d’illustrations est réservée aux comptes admin (allowlist e-mail). Les enseignants utilisent ensuite les missions publiées dans le pilotage de session live.

  1. Connecte-toi avec un compte admin → tu arrives sur Espace admin.
  2. Onglet Missions ou bouton Gérer les missions → studio catalogue.
  3. Clique sur Nouvelle mission (ou Dupliquer une officielle).
  4. Renseigne l’identité (niveau, matière, slug, titre) via « Identité de la mission ».
  5. Pour chaque étape : choisis un type standardisé (QCM, texte libre, texte à trous, nombre, écoute, narration… — valable pour toutes les matières), titre, consigne en texte enrichi (gras / couleurs), réponse si besoin, et onglet Illustration (auto, perso ou scène animée).
  6. Bascule Aperçu élève pour vérifier le rendu, puis Enregistrer.
  7. Coche Publier pour la rendre disponible dans le sélecteur d’activité du pilotage.
Illustrations : onglet Illustrations de l’espace admin (ou « Bibliothèque d’illustrations » depuis le catalogue). Ajoute une image par URL ou fichier (max. 2,5 Mo) : elle apparaît ensuite dans le sélecteur d’étape du studio.
GroupeTypes d’étapeUsage
ParcoursNarration, Méthode, Bilan, ClôtureHistoire, rappel, fin de mission
RéponsesQCM, Texte libre, Texte à trous, Nombre, ÉcouteToutes matières — trous avec ___, écoute = voix
MathsTutoriel / choix / simplification de fraction, DirectionInteractions fractions / spatial
Identifiant : généré automatiquement, du type cm2-maths-test-lecture-01. Une fois publié, il ne doit plus changer (stats / « déjà faite »).
Lecture seule : les missions officielles ne s’éditent pas directement. Duplique-les pour les adapter. Les enseignants sans droit admin n’ont plus le créateur dans l’espace professeur.

8. Astuces, accessibilité et dépannage

Accessibilité & apparence

  • Bouton Écouter dans la barre : lecture à voix haute (recliquer pour arrêter).
  • Bouton Couleurs : panneau avec
    • Mode daltonien — palette deutéranopie (bleu = succès, ambre hachuré = attention).
    • Couleur du site — pastilles proposées ou color picker pour changer boutons et accents.
    • Bouton Couleur par défaut pour revenir au teal Happy Learn.
  • Bouton Classic / NewFront : deux interfaces au choix (NewFront = home sans scroll).
  • L’interface respecte autant que possible les préférences « réduire les animations ».

9. Rappels importants

  • Happy Learn est pensé pour le primaire (CP → CM2).
  • 79 missions officielles couvrent les thèmes du programme (Phase A).
  • Les comptes admin créent et publient missions / illustrations via le studio.
  • Le suivi Programme distingue ce qui est fait dans l’app et en classe.
  • Tu peux basculer Classic / NewFront et personnaliser les couleurs (ou le mode daltonien).
  • Pas de notes, pas de classement : feedback pédagogique uniquement.
  • En classe, privilégie une tablette / ordinateur par élève et un vidéoprojecteur pour le code.
Checklist séance 45 min (exemple)
  1. 5 min — ouvrir la session, écrire le code, élèves en salle d’attente
  2. 2 min — lancer l’activité (mission + mode)
  3. 25–30 min — les élèves jouent ; tu suis la présence
  4. 5 min — arrêt d’activité / bilan oral
  5. 3 min — terminer la session ; consulter les stats plus tard
